# DeepSeek Harness Linux Offline 0.1.0-rc.7-stellaria.1

First Stellaria Studio community pre-release for Linux ARM64.

## Included

- upstream DeepSeek Harness `0.1.0-rc.7`
- Node.js `22.23.2`
- Debian 10 ARM64 glibc `2.28` private compatibility runtime
- complete Linux ARM64 npm cache and 45-package Conda environment lock
- no-sudo atomic installer, rollback, uninstall and read-only diagnostics
- loopback-only Web UI launcher and secure API-key setup
- ELF audits, SHA256 manifest and SPDX 2.3 SBOM

## Qualification

- Static audit: 508 Conda ARM64 ELF and 8 npm ARM64 ELF files
- Highest external requirement: GLIBC 2.28 / GLIBCXX 3.4.32
- Strict offline npm selection: 453 packages
- Archive integrity and clean re-extraction verified on the build host
- GitHub-hosted ARM64 runner: private loader and packaged patchelf execution passed
- Full release-asset offline install smoke runs automatically after publication

## Pre-release boundary

Kylin 10 with kernel 4.4 and host glibc 2.23 remains pending successful
end-to-end device qualification. Kernel 4.4–4.17 is below the current Node.js
Tier 1 Linux ARM64 baseline. Do not treat this pre-release as an official
DeepSeek build or a production qualification for every ARM64 distribution.

Release assets are checksum-protected but not cryptographically signed in this
revision. Verify `SHA256SUMS` before extraction.
